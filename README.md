# Social Links Profile

A responsive social links profile page built as part of a Frontend Mentor challenge.

## Built With

- HTML5
- CSS3
- CSS Custom Properties
- CSS Nesting
- CSS Logical Properties
- CSS Grid
- Responsive design

## Features

- Responsive layout
- Semantic HTML structure
- Accessible keyboard focus states using `:focus-visible`
- CSS custom properties for colors, spacing, typography, and other design tokens
- Modern CSS techniques such as logical properties and CSS nesting

## What I Learned

This project helped me practice building a small component with a clear CSS structure, reusable design tokens, and accessible interactive states. I also focused on keeping the HTML semantic and giving each element a clear responsibility.
